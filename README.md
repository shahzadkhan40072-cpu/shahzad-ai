# SHAHZAD AI

A personal website for the SHAHZAD AI YouTube channel monitoring project.

## Website pages
- `index.html` — project homepage
- `privacy.html` — privacy policy for the current desktop app
- `terms.html` — terms of use

## Enable GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The expected address is:
   https://shahzadkhan40072-cpu.github.io/shahzad-ai/

## Important
The website preview is illustrative. The current desktop monitor uses Google OAuth and the YouTube Data API for read-only monitoring. Review `privacy.html` and update it if the application's data practices change. Never commit OAuth client secrets, token files, API keys, bot tokens or passwords to this repository.

SHAHZAD AI is an independent project and is not affiliated with Google or YouTube.
